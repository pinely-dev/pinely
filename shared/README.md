# Shared Layer

This workspace holds the code shared between the **frontend**, the **backend** and the utility scripts.

It is where every contract address and all chain data live, so the project has a single source of truth.

## Layout

- `chains/index.ts` - The supported (EVM) networks. Imported by the frontend wagmi config.
- `contracts/abis/` - TypeScript ABIs (generated by the sync script).
- `contracts/addresses.ts` - Contract addresses per chain ID (generated).
- `types/` - TypeScript types shared by the frontend and the backend.

Do not edit the files inside `contracts/` by hand. They are overwritten every time you run `bun run sync`.
